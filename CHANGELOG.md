# CHANGELOG

## [3.0.0] - 2026-09-02

Первый релиз на базе WorldPainter 2.27.1 и первый релиз с обычным номером версии. Включает всё из неопубликованной ветки L2.0.2.

### Добавлено

- База обновлена до **WorldPainter 2.27.1**: снова корректно устанавливается точка спавна для Minecraft 26.1 и новее.
- Экспериментальный **[BETA] генератор деревьев**: диалог, движок и 146 ключей `ui.treeGenerator.*` во всех 10 локалях. Пункт меню и заголовок диалога помечены `[BETA]`.
- Кнопка «Обновить сейчас» в диалоге проверки обновлений: приложение штатно закрывается и запускает `WorldPainter-Update.exe`, который докачивает только изменившиеся файлы и перезапускает WorldPainter.
- Ключи `ui.update.installNow` и `ui.update.available.updaterMessage` во всех 10 локалях.
- Апдейтер запрашивает права администратора сам, если папка установки недоступна для записи (установка в `C:\Program Files`); при отказе от UAC ничего не меняется и WorldPainter просто запускается снова.
- Апдейтер ждёт завершения процесса WorldPainter (`--wait-pid`) и повторяет замену файла, пока Windows держит его открытым.
- Протокол обновления пишется в `%LOCALAPPDATA%\WorldPainter Languages\updater.log`; после любой неудачи WorldPainter запускается снова.
- Проверка согласованности версий в сценарии сборки: номер версии, тег релиза, версия для Windows, `pom.xml`, `ForkUpdateChecker.CURRENT_PRODUCT_VERSION`, `installer.iss` и файл release notes должны совпадать, иначе сборка прекращается.
- Генерация CDN-payload для канала обновлений: `release/cdn/app/**`, `release/cdn/update-manifest.txt` и инструкция по публикации (`-GenerateUpdateManifest`).
- Тест T7 в `tools/updater/test-updater-local.ps1`: апдейтер не пытается перезаписать jar, из которого запущен.

### Изменено

- Нумерация версий: форк перешёл на обычные номера (`3.0.0` вместо `2.27.1-L2.1.0`), продолжая ту же линию — `L1` → `L2.0.0` → `L2.0.1` → `3.0.0`. Тег релиза сохраняет букву (`L3.0.0`): сборки до `2.27.0-L2.0.1` искали в теге `L` и число за ней и без буквы не увидели бы релиз вообще.
- Версия базы больше не входит в номер: она хранится в коде и подставляется в окно «О программе» и в имена jar-файлов, поэтому не может разойтись с реальностью. Раньше номер версии был вписан в текст «О программе» во всех одиннадцати локалях и устаревал молча.
- Манифест обновления описывает всю папку `app/`, включая `.cfg`-файлы лаунчеров, и `.cfg` записываются последними — class path переключается на новые jar-файлы только после их появления на диске.
- Jar апдейтера получил версионное имя (`wp-updater-<версия>.jar`), поэтому апдейтер может обновлять сам себя.
- Устаревшие файлы предыдущего релиза попадают в манифест как записи `delete=`; неудачное удаление занятого файла больше не прерывает обновление.
- 110 из 146 ключей генератора деревьев переведены в беларуской, украинской, казахской, немецкой, французской, испанской, итальянской и китайской локалях (раньше оставались английскими).

### Исправлено

- Сравнение версий в проверке обновлений: раньше учитывалась только старшая цифра (`L2`), поэтому `L2.1.0` не считался новее `L2.0.1`. Теперь номер сравнивается целиком, компонент за компонентом.
- «Не напоминать про эту версию» запоминает тег релиза, а не номер ревизии: при сравнении по полному номеру ревизия больше не опознаёт релиз однозначно.
- Кнопка «Обновить сейчас» передаёт апдейтеру `--wait-pid`, поэтому замена jar-файлов начинается только после закрытия WorldPainter (раньше параметр никем не передавался).
- Сценарий упаковки исходников исключал каталог `release` по имени на любом уровне и поэтому молча выбрасывал `tools/release/**` из всех архивов; теперь исключается только `release` в корне проекта.

### Совместимость

- Формат сохранения миров не изменился относительно L2.0.0.
- Обычные миры совместимы с оригинальным WorldPainter 2.27.1.

## [2.27.0-L2.0.1] - 2026-07-28

### Добавлено

- Инкрементальный апдейтер `WorldPainter-Update.exe`: сверка SHA-256 по манифесту, загрузка только изменившихся файлов, атомарная замена, удаление устаревших файлов.
- Генерация `update-manifest.txt` в сценарии сборки (`-GenerateUpdateManifest`, `-UpdateBaseUrl`, `-UpdateManifestUrl`).
- Локальный тест обновления без публикации: `tools/updater/test-updater-local.ps1`.
- Сценарий чистой упаковки релизных архивов: `tools/release/pack-release-archives.ps1`.

### Удалено

- Экспериментальный генератор деревьев: диалог, движок и 146 ключей `ui.treeGenerator.*` в каждой из 10 локалей.

### Совместимость

- Формат сохранения миров не изменился относительно L2.0.0.

## [2.27.0-L2.0.0] - 2026-07-21

Второй публичный релиз после L1, основанный на WorldPainter 2.27.0.

### Добавлено

- Пять локализаций: немецкая, французская, испанская, итальянская и упрощённая китайская.
- Полный паритет десяти локалей во всех девяти семействах ресурсов.
- Пользовательский слой **[BETA] Система пещер** (`CaveSystem`) с трёхмерным полем плотности, крупными шумовыми залами, cheese/grand-полостями, spaghetti/backbone/noodle-тоннелями, выходами, аквиферами, пышными и натёчными областями.
- Пользовательский слой **[BETA] Айсберги**.
- Терейны `ICE` и `PACKED_ICE`.
- Команда сохранения независимой совместимой копии мира для оригинального WorldPainter 2.27.0.
- Темы FlatLaf Cyan light и FlatLaf One Dark с отдельными наборами интерфейсных иконок.
- 1107 иконок блоков/материалов и 95 sprite-иконок биомов.
- Современный Windows `IFileDialog` с fallback на Swing.
- Автоматическая и ручная проверка обновлений форка.
- Windows file association для `.world` и новый packaging toolkit для Portable, WiX/MSI и Inno Setup.
- Документация сборки и локализации.

### Изменено

- Полностью расширено покрытие локализации UI, редких диалогов, инструментов и progress-сообщений.
- Терминология блоков, растений и биомов сверена с Minecraft и локализованными Minecraft Wiki.
- 150 хэш-ключей локализации переименованы в осмысленные стабильные имена.
- FlatLaf Cyan light стала темой по умолчанию; старые удалённые темы безопасно мигрируют через compatibility aliases.
- Иконки слоёв, операций, панелей и JIDE controls стали theme-aware.
- Windows packaging вынесен из runtime-дерева в `tools/windows-packaging/`.
- Обновлены README, NOTICE, copyright headers и release metadata.

### Исправлено

- JIDE docking tooltip, цвета и динамически пересоздаваемые элементы.
- Ошибки компиляции и startup crash, найденные во время очистки тем.
- Повреждённые локализованные строки, MessageFormat placeholders, escape-последовательности и HTML.
- Зависимость игровых иконок от локализованных display names.
- Большие пустые области и чрезмерная плотность в последовательных итерациях генератора пещер.

### Совместимость

- Миры без fork-only слоёв совместимы с оригинальным WorldPainter 2.27.0.
- Для миров с `CaveSystem`, `Icebergs`, `ICE` или `PACKED_ICE` добавлена отдельная команда сохранения совместимой копии.
- Deprecated enum-значения сохранены для чтения старых конфигураций.

Полный список изменений и проверенный файловый diff: [docs/CHANGES_L1_TO_L2_RU.md](docs/CHANGES_L1_TO_L2_RU.md).

## [2.27.0-L1] - 2026-07-11

Первый публичный релиз **WorldPainter Languages** на базе WorldPainter 2.27.0.

### Добавлено

- Украинская (`uk`), белорусская (`be`) и казахская (`kk`) локализации в полном паритете с русской.
- Разделение переводов на доменные bundle-файлы: strings, blocks, gamedata, layers, swing.
- Маршрутизация ключей по префиксу в WPI18n с fallback на основной bundle.
- Просьба поставить звёздочку репозиторию в диалоге поддержки.

### Изменено

- Настройки хранятся в отдельной папке `WorldPainter Languages`; при первом запуске существующие настройки копируются из старой папки `WorldPainter`, не изменяя оригинал.
- Проект переименован в WorldPainter Languages.
- Диалог поддержки обновлён под новый бренд.
- `.properties` приведены к UTF-8 без `\\uXXXX`-эскейпов.
- Выполнена вычитка RU/UK/BE/KK.

### Удалено

- 195 неиспользуемых ключей локализации, синхронно во всех языках.
- Внутренние инструменты и черновые документы из release-дерева.
