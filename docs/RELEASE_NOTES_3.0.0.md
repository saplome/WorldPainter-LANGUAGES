# WorldPainter Languages 3.0.0

Неофициальный форк WorldPainter 2.27.1 с интерфейсом на 11 языках. Java устанавливать не нужно — она внутри сборки.

## Что нового

- **Обновление одной кнопкой.** В диалоге проверки обновлений появилась кнопка **«Обновить сейчас»**: программа закрывается, докачивает только изменившиеся файлы и запускается снова. Раньше установщик приходилось скачивать вручную. Если обновиться не удалось — нет сети, отклонён запрос прав, — WorldPainter просто запускается в прежнем виде.
- **Основа обновлена до WorldPainter 2.27.1.** Снова правильно ставится точка спавна для Minecraft 26.1 и новее.
- **[BETA] Генератор деревьев** — новый диалог со своим движком, переведённый на все языки интерфейса. Функция ещё в разработке, поэтому помечена `[BETA]`.
- **Отчёт об ошибке уходит в трекер форка.** Кнопка в диалоге ошибки копирует отчёт в буфер обмена и открывает [страницу задач](https://github.com/saplome/WorldPainter-LANGUAGES/issues), где его нужно вставить в новую задачу. Раньше письмо адресовалось автору оригинального WorldPainter, который ошибки форка не исправляет.
- **В заголовке окна теперь название форка** — WorldPainter Languages, и с открытым миром, и без. В беларуской, казахской, русской и украинской локалях в заголовке вернулся пробел: раньше читалось `WorldPainter -Мир`.
- **Обычные номера версий.** Вместо `2.27.1-L2.1.0` — просто **3.0.0**, та же линия, что и раньше: L1 → L2.0.0 → L2.0.1 → 3.0.0. На какой версии WorldPainter собран форк, теперь написано отдельно, в окне «О программе».
- **Лицензия рядом с программой.** `LICENSE`, `NOTICE.md` и `CHANGELOG.md` лежат в папке установки и в портативной сборке, как того требует GPL.

## Что скачать

| Файл | Для чего |
| --- | --- |
| `WorldPainter-Languages-3.0.0-Setup.exe` | обычная установка в Windows |
| `WorldPainter-Languages-3.0.0-Portable.zip` | распаковать и запустить, без установки |
| `update-manifest.txt` | служебный файл для встроенного обновления, скачивать не нужно |

Исходный код — в `Source code (zip)`: GitHub собирает этот архив из тега релиза, поэтому он не может разойтись с опубликованной сборкой.

## Как обновиться

- **С 3.0.0 и дальше** — кнопкой **«Обновить сейчас»** в самой программе.
- **С L2.0.1** — либо запустить `WorldPainter-Update.exe` из папки установки (для установки в `C:\Program Files` — от имени администратора; для портативной версии права не нужны), либо поставить `Setup.exe` поверх текущей версии.
- **С L2.0.0 и L1** — поставить `Setup.exe` поверх текущей версии: апдейтера в тех сборках ещё нет.

Настройки и миры обновление не затрагивает — заменяются только файлы программы.

## Совместимость

Миры без возможностей форка открываются в оригинальном WorldPainter 2.27.1. Если в мире есть слои **[BETA] Система пещер** или **[BETA] Айсберги** либо терейны `ICE` и `PACKED_ICE`, сохраните для него отдельную копию командой **«Сохранить копию для оригинального WorldPainter…»**. Формат сохранения миров не менялся с L2.0.0.
