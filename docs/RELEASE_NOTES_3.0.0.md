# WorldPainter Languages 3.0.0

Неофициальный многоязычный форк WorldPainter 2.27.1.

## Что нового в 3.0.0

### Своя нумерация версий

- Форк перешёл на обычные номера: **3.0.0**. Это продолжение той же линии, что и раньше — `L1` → `L2.0.0` → `L2.0.1` → `3.0.0`, — только без версии базы в номере.
- Версия WorldPainter, на которой собран форк, теперь указана отдельно: в окне **«О программе»** («Версия 3.0.0 … форк WorldPainter 2.27.1») и в именах jar-файлов (`WPGUI-2.27.1.jar`). Она берётся из кода, поэтому разойтись с реальностью не может.
- Тег релиза — `L3.0.0`. Буква нужна для совместимости: сборки до `2.27.0-L2.0.1` искали в теге `L` и число за ней, поэтому без неё они бы вообще не заметили новый релиз.

### База обновлена до WorldPainter 2.27.1

- Влит официальный релиз 2.27.1: снова корректно устанавливается точка спавна для Minecraft 26.1 и новее.

### Обновление одной кнопкой

- В диалоге проверки обновлений появилась кнопка **«Обновить сейчас»**: WorldPainter штатно закрывается и запускает `WorldPainter-Update.exe`, который докачивает только изменившиеся файлы и перезапускает программу.
- Манифест обновления описывает всю папку `app/`, включая `.cfg`-файлы лаунчеров, поэтому обновление переключает class path на новые jar-файлы, а не оставляет его на старых.
- Апдейтер умеет обновлять сам себя: его jar называется по версии (`wp-updater-3.0.0.jar`) и приезжает как новый файл, а не как замена занятого.
- Устаревшие файлы прошлых версий удаляются по записям `delete=` в манифесте.
- При установке в `C:\Program Files` апдейтер сам перезапускается с запросом прав администратора; если UAC отклонён, обновление прекращается без изменений.
- Каждый файл сверяется по размеру и SHA-256, скачивается во временный `*.wpupdate-tmp` и заменяется атомарно. При несовпадении хэша установка остаётся нетронутой.
- Апдейтер ждёт, пока WorldPainter полностью закроется, и повторяет замену файла, если Windows всё ещё держит его открытым.
- Любая неудача не оставляет пользователя без программы: WorldPainter запускается снова, а протокол каждого запуска дописывается в `%LOCALAPPDATA%\WorldPainter Languages\updater.log`.
- Исправлено сравнение версий: сравнивается весь номер, компонент за компонентом, а не только старшая цифра. Раньше `L2.1.0` не считался новее, чем `L2.0.1`.

### Генератор деревьев

## Состав релиза

| Файл | Назначение |
| --- | --- |
| `WorldPainter-Languages-3.0.0-Setup.exe` | установка в Windows (Inno Setup, со встроенной Java 21) |
| `WorldPainter-Languages-3.0.0-Portable.zip` | переносимая сборка со встроенной Java-средой |
| `WorldPainter-Languages-3.0.0.zip` | исходный код без сценариев релизной упаковки |
| `WorldPainter-Languages-3.0.0-github-ready.zip` | исходный код вместе с `tools/` — для прямого коммита в репозиторий |
| `WorldPainter-Languages-3.0.0-release-tools.zip` | только `tools/`: сборка Portable, установщика и релизных архивов |
| `update-manifest.txt` | манифест инкрементального обновления |

## Обновление с L2.0.1

L2.0.1 об этом релизе сообщит сам (в теге есть `L3`), но кнопка в том диалоге умеет только открыть страницу релиза — установить обновление она не может. Дальше два равноценных пути:

- запустить `WorldPainter-Update.exe` из папки установки, **от имени администратора** для установки в `Program Files` (для портативной версии права не нужны). Апдейтер из L2.0.1 понимает текущий манифест и обновит установку целиком, включая `.cfg`-файлы;
- либо установить `WorldPainter-Languages-3.0.0-Setup.exe` поверх текущей версии.

После перехода на 3.0.0 обновления ставятся кнопкой **«Обновить сейчас»** прямо из приложения. Если обновление не удалось (нет сети, отклонён запрос прав), WorldPainter запускается снова сам, а подробности каждого запуска дописываются в `%LOCALAPPDATA%\WorldPainter Languages\updater.log`.

## Обновление с L2.0.0 и L1

Апдейтера в этих сборках нет, а в L1 нет и проверки обновлений, поэтому нужна разовая установка `WorldPainter-Languages-3.0.0-Setup.exe` поверх текущей версии.

## Совместимость

Обычные миры без возможностей форка совместимы с оригинальным WorldPainter 2.27.1. Для миров с `CaveSystem`, `Icebergs`, `ICE` или `PACKED_ICE` используйте команду **«Сохранить копию для оригинального WorldPainter…»**.

Внутренний ID слоя: `org.pepsoft.CaveSystem`. Формат сохранения не изменился относительно L2.0.0.
