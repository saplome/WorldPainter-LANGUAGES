# WorldPainter Languages 2.27.0-L2.0.1

Неофициальный многоязычный форк WorldPainter 2.27.0.

## Что нового в L2.0.1

- Инкрементальное обновление: отдельный лаунчер `WorldPainter-Update.exe` скачивает только изменившиеся файлы по манифесту с SHA-256, полная переустановка больше не нужна.
- Проверка целостности каждого файла и атомарная замена: прерванное обновление не оставляет повреждённых файлов.
- Из сборки удалён экспериментальный генератор деревьев.
- Обновлены сценарии упаковки: сборка апдейтера, генерация `update-manifest.txt` и чистые релизные архивы.

## Состав релиза

| Файл | Назначение |
| --- | --- |
| `WorldPainter-Languages-2.27.0-L2.0.1-Setup.exe` | установка в Windows |
| `WorldPainter-Languages-2.27.0-L2.0.1-Portable.zip` | переносимая сборка со встроенной Java-средой |
| `WorldPainter-Languages-2.27.0-L2.0.1.zip` | исходный код без сценариев упаковки |
| `update-manifest.txt` | манифест для инкрементального обновления |

## Обновление с предыдущей версии

Запустите `WorldPainter-Update.exe` из папки установки. Обновятся только изменившиеся файлы.

## Совместимость

Обычные миры без возможностей форка совместимы с оригинальным WorldPainter 2.27.0. Для миров с `CaveSystem`, `Icebergs`, `ICE` или `PACKED_ICE` используйте команду **«Сохранить копию для оригинального WorldPainter…»**.

Внутренний ID слоя: `org.pepsoft.CaveSystem`. Формат сохранения миров не изменился.
