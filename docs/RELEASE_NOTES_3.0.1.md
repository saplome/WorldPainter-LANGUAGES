# WorldPainter Languages 3.0.1

Неофициальный форк WorldPainter 2.27.1 с интерфейсом на 11 языках. Java устанавливать не нужно — она внутри сборки.

## Что нового

**Сборка стала легче на треть.** Java внутри неё была целой средой разработки: компилятор, отладчик, консоль `jshell`, инструменты упаковки и данные всех языков мира — 44 лишних компонента, которые программа никогда не открывает. Осталось только то, что действительно нужно.

| | 3.0.0 | 3.0.1 |
| --- | --- | --- |
| `Setup.exe` | 58.4 МБ | **45.8 МБ** |
| `Portable.zip` | 77.1 МБ | **56.0 МБ** |
| на диске после установки | 163 МБ | **108 МБ** |

Возможности не изменились: все 11 языков, экспорт миров, скрипты в собственных объектах, иконки растений из `.jar` Minecraft, проверка обновлений и обновление одной кнопкой работают как раньше. Названия месяцев и разделитель дробной части остались правильными для всех одиннадцати языков — данные именно этих языков в сборке и оставлены.

## Что скачать

| Файл | Для чего |
| --- | --- |
| `WorldPainter-Languages-3.0.1-Setup.exe` | обычная установка в Windows |
| `WorldPainter-Languages-3.0.1-Portable.zip` | распаковать и запустить, без установки |
| `update-manifest.txt` | служебный файл для встроенного обновления, скачивать не нужно |

Исходный код — в `Source code (zip)`: GitHub собирает этот архив из тега релиза, поэтому он не может разойтись с опубликованной сборкой.

## Как обновиться

- **С 3.0.0** — кнопкой **«Обновить сейчас»** в самой программе: она докачает около 10 МБ изменившихся файлов. Но обновление заменяет только файлы программы, а Java остаётся той, что уже установлена, то есть полной. Чтобы освободить эти 55 МБ на диске, поставьте `Setup.exe` поверх текущей установки или распакуйте `Portable.zip` заново.
- **С L2.0.1** — либо запустить `WorldPainter-Update.exe` из папки установки (для установки в `C:\Program Files` — от имени администратора; для портативной версии права не нужны), либо поставить `Setup.exe` поверх текущей версии.
- **С L2.0.0 и L1** — поставить `Setup.exe` поверх текущей версии: апдейтера в тех сборках ещё нет.

Настройки и миры обновление не затрагивает — заменяются только файлы программы.

## Совместимость

Миры без возможностей форка открываются в оригинальном WorldPainter 2.27.1. Если в мире есть слои **[BETA] Система пещер** или **[BETA] Айсберги** либо терейны `ICE` и `PACKED_ICE`, сохраните для него отдельную копию командой **«Сохранить копию для оригинального WorldPainter…»**. Формат сохранения миров не менялся с L2.0.0.
